# AI LINE CRM 実機テストチェックリスト

## 目的

LINEアプリ上で、リッチメニュー、自動返信、タグ付け、シナリオ起動が期待通り動くか確認する。

## 前提

- Worker API が起動している
- LINE Webhook が現在のWorker URLへ向いている
- リッチメニュー `AI CRM MVP Rich Menu` がデフォルト設定済み
- 管理画面にログインできる

## 1. リッチメニュー表示

LINE公式アカウントを開き、以下6項目が表示されることを確認する。

- 無料ガイド
- AI診断
- 導入相談
- AI講座
- 勉強会
- 質問する

## 2. リッチメニュークリック

各ボタンを押し、LINEトーク上に以下のメッセージが送信されることを確認する。

| ボタン | 送信される文字 |
|---|---|
| 無料ガイド | ガイド |
| AI診断 | AI診断 |
| 導入相談 | 導入相談 |
| AI講座 | 講座 |
| 勉強会 | 勉強会 |
| 質問する | 質問 |

## 3. 自動返信

以下の返信が返ることを確認する。

| 入力 | 期待する反応 |
|---|---|
| ガイド | 特典一覧案内 |
| AI診断 | 8択診断案内 |
| 導入相談 | 相談フォーム/予約導線 |
| 講座 | AI講座案内 |
| 勉強会 | 勉強会案内 |
| 質問 | 自由質問案内 |
| 料金 | 料金・サービス案内 |

## 4. 初回診断の数字返信

`AI診断` のあと、数字で返信して自動返信とタグ付けを確認する。

| 入力 | 期待タグ |
|---|---|
| 1 | 興味_実務活用 / 課題_何から始めるかわからない / 温度_中 |
| 2 | 興味_AIエージェント / 興味_業務自動化 / 温度_高 / 商談候補 |
| 3 | 興味_業務自動化 / 課題_業務効率化 / 温度_高 / 商談候補 |
| 4 | 興味_AI講座 / 興味_AIブートキャンプ / 商品_AIブートキャンプ / 温度_中 |
| 5 | 商品_個別AI講座 / 温度_高 / 商談候補 |
| 6 | 興味_勉強会 / 温度_中 |
| 7 | 資料請求済 / 温度_低 |
| 8 | 温度_中 |

## 5. 管理画面確認

管理画面で以下を見る。

- `友だち管理`: 対象友だちにタグが付いている
- `個別チャット`: 自動返信ログが残っている
- `AI CRM`: 構築率とファネル状態が表示されている
- `オートメーション`: `AI CRM タグ付け: ...` が有効

## 6. 短縮シナリオテスト

管理画面で対象友だちに以下タグを付与する。

```text
テスト_短縮配信
```

期待する配信:

- 0分: テスト開始
- 1分後: Day1相当
- 2分後: Day3相当
- 3分後: Day5相当
- 4分後: Day7相当

## 7. 問題が出たとき

確認順:

1. Workerが起動しているか
2. Webhook URLが正しいか
3. LINE DevelopersのAuto-reply/GreetingがOFFか
4. `.dev.vars` のLINEトークンが正しいか
5. 管理画面の対象友だちにタグが付いているか
6. `messages_log` に送信履歴が残っているか
