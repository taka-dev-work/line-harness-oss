# AI LINE CRM 公開用リンク集

本番LINE公式アカウントへ流入させるための公開用リンクです。

## LINE公式アカウント

- 表示名: YOUR_LINE_ACCOUNT_NAME
- Basic ID: `@YOUR_BASIC_ID`
- 直接追加URL: `https://line.me/R/ti/p/@YOUR_BASIC_ID`

## 流入元別の計測リンク

| 流入元 | 掲載URL |
| --- | --- |
| Xプロフィール | `https://YOUR_WORKER_DOMAIN/t/YOUR_X_REF_ID` |
| note記事 | `https://YOUR_WORKER_DOMAIN/t/YOUR_NOTE_REF_ID` |
| LP | `https://YOUR_WORKER_DOMAIN/t/YOUR_LP_REF_ID` |
| 勉強会・セミナー | `https://YOUR_WORKER_DOMAIN/t/YOUR_EVENT_REF_ID` |


## QRコードURL

QRコード画像が必要な場合は、以下の `data=` に掲載URLを入れて開きます。

```text
https://YOUR_WORKER_DOMAIN/api/qr?size=480x480&data=掲載URL
```
